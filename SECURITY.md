# Security policy

## Reporting a vulnerability

If you find a security issue in this code or on https://koreanpages.com.au, please report it privately:

- **Email:** bjhbrian916@gmail.com, subject `[security] koreanpages`
- or open a **private security advisory** on this repository (Security → Advisories → Report a vulnerability)

Please include steps to reproduce and the impact you expect. I'll acknowledge reports within 3 days and keep you updated until a fix is deployed.

Please don't test against the live site in ways that affect other users: no denial-of-service, no automated scanning at volume, and no access to data that isn't yours.

## Scope

| In scope | Out of scope |
|---|---|
| Code in this repository | The original CMS's page templates (vendor code, not published here) |
| koreanpages.com.au and its admin | Third-party services (AWS, Google, Anthropic) |

## Known issues

Open findings are listed publicly in [docs/open-findings.md](docs/open-findings.md). Reports of those are welcome if you have new detail.
